# T115 — 웹 UI 확인용 샘플 데이터

## 상태와 목적

- 기준: 2026-10-02 dev
- 백로그 상태: `in_progress` / 에픽: `E11` / 예상: 20분

실제 데이터 없이 브라우저의 전체 작업 흐름을 빠르게 확인할 수 있는 작은 입력 폴더를 제공한다.

## 범위와 완료 기준

1. `samples/web-demo` 폴더를 업로드해 결과 화면까지 실행할 수 있다.
2. 같은 스키마 파일과 다른 스키마 파일이 함께 있어 그룹 판별을 확인할 수 있다.
3. 행 수와 컬럼 구성을 문서화하고 생성 명령을 재현할 수 있다.

## 구현

- 기존 [scripts/make_sample_data.py](../../scripts/make_sample_data.py)를 고정 seed로 재사용한다.
- 매출 파일 2개에 각 1,500행, 고객 파일 1개에 1,000행을 생성한다.
- [samples/README.md](../../samples/README.md)에 업로드 방법과 데이터 구성을 기록한다.

## 검증 계획

- 세 CSV를 pandas로 읽어 행 수와 스키마 구성을 확인한다.
- `run_folder_pipeline`으로 폴더 전체를 처리해 성공 그룹과 축소 결과가 생성되는지 확인한다.
- `python backlog.py validate`, 전체 lint/build를 통과시킨다.
