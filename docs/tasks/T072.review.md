## Adversarial checks

- Extension checks are case-insensitive; a synthetic uppercase `.TSV` file was accepted.
- A nested synthetic folder displayed three relative paths, 52 total bytes, and one excluded Markdown file.
- No file contents or absolute filesystem paths are rendered; only browser-provided relative paths and sizes are retained.
- Empty `FileList`, unsupported-only folders, unavailable entry APIs, unreadable entries, and files without `webkitRelativePath` have deterministic fallbacks.
- Directory readers are called repeatedly until an empty batch, avoiding Chromium's per-batch truncation behavior.
- Drag depth is bounded at zero and reset on drop, avoiding a stuck active style when moving across child elements.
- A failed recursive read replaces any stale selection with the empty guidance instead of leaving an unhandled rejection.
- Large selections retain only `File` metadata references and use a bounded scrolling list.
- The chooser button, hidden input label, live selection summary, list semantics, and focus outlines provide accessible operation and feedback.
- At 390×844 the heading and drop zone remain inside the viewport; `/results` still renders its prior empty state.
- `FolderPicker.tsx` is 154/250 non-blank lines; all functions are below the 80-line limit. `App.tsx` is 123/250.
- No server upload, API call, job creation, content parsing, or route transition was added outside T072 scope.
