# T113 adversarial review

## 검토 범위

- core pipeline 진행 콜백, 그룹별 진행 구간 및 실패/건너뜀 경계
- API의 원자적 상태 저장과 RunPanel에서 읽는 `progress`/`stage` 계약
- 전체 백엔드 테스트 및 품질 검사

## 검증

- core는 파일·스키마 확인, 그룹별 병합/전처리, 크기 탐색, 방식 비교, 투영 단계를 보고한다. 그룹 수에 따라 구간을 나누며 실패로 건너뛴 그룹도 해당 구간을 소모한다.
- 진행 fraction은 core 기준 0~1, API 기준 20~85%로 변환되며 저장 90%, 완료 100%는 기존 경계로 유지된다. API writer가 진행률 감소를 막고 그룹 단계명을 상태에 기록한다.
- 오류는 마지막 실제 단계와 진행값을 사용한다. 저장 단계 실패도 `결과 저장`으로 표시된다. 콜백 자체의 `ValueError`는 그룹 실패로 오인되지 않고 실행 오류로 전파된다.
- `frontend/src/RunPanel.tsx`가 기존에 상태 API의 값을 그대로 표시하므로 화면 구현 변경은 불필요하다.
- UTF-8 환경 전체 백엔드 회귀 344 passed, Ruff 및 compileall 통과. FastAPI TestClient의 `httpx` deprecation 경고만 남는다.

## 발견 사항

없음. 빈 입력, 잘못된 그룹 건너뜀, callback 오류, 단계 저장/실패, 결과 저장 실패 경계를 확인했다.

Verdict: PASS
