# T058 — 결측 많은 컬럼 자동 제외와 원인 안내

## 문서 성격과 현재 상태

기존 작업의 사후 보완 문서다. 당시 Task Analysis·리뷰 기록을 새로 만든 것으로 취급하지 않는다.

- 기준: 2026-10-01 dev `019ee84`
- 백로그 상태: `done` / 에픽: `E2` / 예상: 20분
- 후행 작업: 없음

## 쉽게 이해하기

빈 값이 너무 많은 컬럼을 기본 선택에서 빼고, 전처리 후 행이 0개이면 원인을 알려준다.

## 의존 작업

- [T025](T025.md): `done` — 전처리: 결측치·이상치 처리

## 범위와 완료 기준

별도 설명이 없어 제목과 다음 완료 기준을 작업 범위로 사용한다.

1. 결측률이 기준을 넘는 컬럼은 기본 선택에서 빠진다
2. 남는 행이 0이면 원인 컬럼과 결측률을 알려준다

이 문서는 범위 밖의 기능 구현, 백로그 상태 변경, 새 리뷰 판정을 수행하지 않는다.

## 관련 요구사항

[problem.md](../../problem.md)의 §3 입력 데이터, §4 축소 기준 컬럼을 참고한다. 제목과 절 구성은 작업 시작 때 다시 확인한다.

## 현재 코드 근거와 관련 파일

- [backend/app/core/prepare.py](../../backend/app/core/prepare.py) — 현재 존재하는 참고 파일.
- [backend/app/core/schema.py](../../backend/app/core/schema.py) — 현재 존재하는 참고 파일.
- `missing_reason`: 남는 행이 0일 때, 어떤 컬럼 때문인지 알려주는 메시지를 만든다.
- `missing_report`: 기준 컬럼별 결측 비율을 큰 순서로 돌려준다.

주의: 기본 제외의 근거는 schema.classify_column에도 있다. missing_reason은 남은 행이 없는 경우 설명을 만든다.
