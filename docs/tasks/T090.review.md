# T090 적대적 리뷰

Verdict: PASS

## 완료 기준 대조

- 드롭다운에서 2D/3D 산점도, 히스토그램, 박스플롯, 상관 네트워크를 선택하면 패널 제목이 즉시 바뀐다.
- 나란히 모드는 원본/축소본 두 패널, 겹쳐보기는 결합 패널 하나를 표시한다.
- 선택 그룹마다 `GroupSummary`가 다시 마운트되어 그래프 컨트롤도 일관된 초기 상태로 시작한다.

## 경계·회귀 검토

- 보기 버튼은 `aria-pressed`, 변경 영역은 `aria-live`로 상태를 전달한다.
- 좁은 화면에서는 컨트롤과 두 비교 패널을 세로로 배치한다.
- 실제 렌더러를 포함하지 않아 후속 태스크의 데이터 로딩·차트 구현과 책임이 섞이지 않는다.
- 모든 후속 그래프 종류를 하나의 안정된 값 집합으로 제공한다.
- 샘플 이미지는 렌더러가 아닌 공통 컨테이너 예시임을 명시했다.
