## Finding

1. **P1 — A validated font file does not guarantee Matplotlib renders with that same file.** `scripts/plot_compare.py:39-44` accepts the first matching `FontEntry` whose file passes `_has_hangul`, but then configures `font.family` using only `name`. If two entries share that family name and another entry lacks Hangul (for example regular vs alternate/localized files), Matplotlib's resolver may select the unverified sibling based on style/weight and emit the same missing-glyph warnings T108 is meant to prevent. Reproduce at the selection level with two `FontEntry` objects named `Malgun Gothic`, one failing and one passing: `_pick_font` returns Korean labels even though the family still contains an unverified selectable file. Require every selectable entry for the chosen family to pass validation, or configure rendering with a mechanism that pins the verified file; add a same-family mixed-glyph regression test.
