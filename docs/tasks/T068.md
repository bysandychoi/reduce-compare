# T068 Task Analysis — 그룹 단위 축소: 층화 컬럼 결측값 처리

## Task and dependency status

- Task: T068, 그룹 단위 축소: 층화 컬럼 결측값 처리
- Status: `todo` at analysis time; move to `in_progress` before implementation.
- Estimate: 20 minutes
- Dependencies: none
- Downstream tasks: none
- Active branch: `dev`

## Scope

- Make `combo_key` normalize `NaN`, `None`, and `pd.NA` in unit/strata/comparison columns to one explicit string category.
- Ensure grouped unit tables, stratified selection, row weights, and stratum reports work when strata contain missing values.
- Add focused regression tests for mixed missing representations and multi-column keys.
- Preserve current behavior for inputs without missing values.

## Non-goals

- Changing the general reduction pipeline's rule that removes rows missing selected feature columns.
- Imputing numeric values, dropping grouped-CLI rows, or changing sampling ratios and minimum-unit allocation.
- Redesigning key escaping for the existing internal separator or defining a user-configurable missing label.
- Changing CLI options, report schemas, generated artifact encodings, or frontend/API behavior.

## Technical approach

- Add a module-level Korean missing-category label such as `"(결측)"` in `backend/app/core/grouped.py`.
- Before string conversion, view selected columns as objects and replace every `isna()` value with that label; then keep the existing vectorized key concatenation path.
- Remove the current fallback row-wise `SEP.join` branch, which is both slower and the source of the pandas 3 type error.
- Add a dedicated grouped regression test covering key equality, distinct non-missing strata, finite weights, count preservation, and report visibility.

## Acceptance criteria

1. Multi-column `combo_key` returns strings and never raises when selected columns contain `NaN`, `None`, or `pd.NA`.
2. All missing representations in the same column map to one `"(결측)"` category while non-missing values remain distinct.
3. `stratified_units` completes with missing strata, returns finite row weights, and preserves each retained stratum's weighted original row total.
4. `stratum_report` includes the missing stratum rather than silently dropping it.
5. Focused tests, full backend tests in default Windows and UTF-8 conditions, Ruff/compile checks, frontend gates, and diff checks pass.

## Relevant requirements

- `problem.md` §3: input data can contain missing values and the handling must be explicit.
- `problem.md` §4: grouped/unit reduction preserves chosen units and automatically maintains strata proportions.
- `problem.md` §5: distribution and grouped similarity calculations depend on stable category keys.
- T068 backlog acceptance: missing strata/comparison values are treated as one category and a regression test prevents the prior `TypeError`.

## Existing and expected files

- New: `backend/tests/test_grouped_missing.py`: focused missing-category and grouped-reduction regression tests.

- `scripts/units_report.py` and `backend/app/core/catmetrics.py`: downstream consumers verified through tests, no change expected.

## Test plan

- Verify exact multi-column keys for regular, `NaN`, `None`, and `pd.NA` rows.
- Run grouped stratified reduction with a fixed seed and missing strata; assert finite weights and weighted counts.
- Build a stratum report and assert the missing category appears with the correct original counts.
- Run existing unit-limit/unit-set tests plus the new focused tests.
- Run full backend suites in default and UTF-8 modes, Ruff, compileall, frontend lint/build, and `git diff --check`.

## Edge cases and risks

- Pandas string dtypes may preserve missing sentinels through `astype(str)`; replacement must happen before conversion.
- Categorical columns may reject a new fill value unless converted to object first.
- Multiple missing representations must collapse to one key, not the literal strings `nan`, `None`, and `<NA>`.
- Missing values in unit columns use the same normalization because `combo_key` is shared.
- A real data value equal to `"(결측)"` will share the missing category; this label policy is accepted by the backlog example and key escaping is outside T068.
