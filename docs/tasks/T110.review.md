## 검토 범위

- 완료 기준: 입력 단계별 시간 리포트 출력
- 요구사항: 50만 행 2분 목표와 비교하되, 실제 측정 구간의 한계를 구분
- 구현: [scripts/benchmark.py](../../scripts/benchmark.py), Task Analysis와 실행 검증 기록

## 검증

- 단계별 보고: PASS. 폴더 탐색/스키마, 병합/전처리, 크기 탐색, 방식 비교, 투영 및 전체 시간을 텍스트와 JSON으로 제공한다.
- 규모/목표 비교: PASS. 1만/10만/50만 그룹 A 행 요청을 실측하고 그룹 B를 포함한 전체 행도 표시한다. 실행된 합성 시나리오 세 개 모두 120초 미만이었다. 브라우저 업로드·렌더링을 제외한 결과라는 한계를 명시했다.
- 실패/경계 사례: PASS. 0행과 없는 폴더를 거부한다. 임시 합성 파일을 사용하고 임시 디렉터리를 자동 정리한다.
- 이전 지적 재검증: `--folder`의 CSV 파일과 같은 `--json` 경로를 지정했을 때 종료 코드 2로 실패하며 SHA-256이 전후 동일했다. 별도 출력 경로로는 유효한 JSON을 기록했다.
- 품질: Ruff, compileall, `git diff --check` 통과. 스크립트는 200줄 제한 이내다.
