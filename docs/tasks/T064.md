## 범위와 완료 기준

결과 객체와 그래프 데이터 반환

1. GET /jobs/{id}/result가 스키마대로 반환
2. 실행 전/진행 중/실패 결과와 손상된 완료 결과를 구분
3. 절대 서버 경로 없이 그룹 요약·지표·곡선·그래프 좌표 반환

## 구현 계획

1. `backend/app/api/results.py`에 T055 `PipelineResults` 응답 엔드포인트를 둔다.
2. `run.json`이 `done`일 때만 `result.json`을 스키마 검증 후 반환한다.
3. 실제 백그라운드 완료 결과, 준비 전, 실패, 없는 job, 손상 파일을 API 테스트한다.
