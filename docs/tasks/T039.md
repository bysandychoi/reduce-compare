# T039 — 그룹 단위 층화 축소 (행이 묶여 있는 데이터)

## 문서 성격과 현재 상태

기존 작업의 사후 보완 문서다. 당시 Task Analysis·리뷰 기록을 새로 만든 것으로 취급하지 않는다.

- 기준: 2026-10-01 dev `019ee84`
- 백로그 상태: `done` / 에픽: `E3` / 예상: 30분
- 후행 작업: [T059](T059.md), [T310](T310.md)

## 쉽게 이해하기

한 lot처럼 여러 행이 묶여야 하는 단위를 통째로 뽑는다. 행 하나만 뽑아 단위가 잘리는 것을 방지한다.

## 의존 작업

- [T030](T030.md): `done` — 축소기 공통 인터페이스 정의

## 범위와 완료 기준

별도 설명이 없어 제목과 다음 완료 기준을 작업 범위로 사용한다.

1. 지정한 단위의 행은 통째로 유지
2. 층 조합별 비율 유지, 드문 조합 최소 1개 보장

이 문서는 범위 밖의 기능 구현, 백로그 상태 변경, 새 리뷰 판정을 수행하지 않는다.
