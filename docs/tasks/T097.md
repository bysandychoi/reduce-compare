# T097 Task Analysis — 상관 네트워크 그래프 데이터

- Status at analysis: todo; dependency T042: done. User selected T097.
- Branch: dev. Downstream task: T098 (rendering).

## Scope and requirements

`problem.md` §§7–9 specifies columns as nodes, one undirected edge per
column pair with |r| >= threshold, width based on |r|, and color based on sign.
Add a reusable backend function accepting ordered column names and a correlation
matrix. Its output is JSON-compatible nodes and edges, plus the threshold.
Keep all nodes, including isolated ones, in input order; never generate self-links
or duplicate edges. Preserve signed correlation, absolute weight, and sign.
The same column order gives original and reduced graphs the same node IDs.

## Non-goals

No API endpoint, frontend layout, relationship-change classification, Spearman
calculation, or changes to existing metric scores. No graph library dependency.

## Acceptance criteria

1. Changing threshold within [0, 1] changes edges according to inclusive |r|.
2. Negative and positive correlations are both represented with correct weights/signs.
3. Nodes remain stable across original/reduced matrices and threshold changes.
4. Empty/single-column graphs work. Undefined (NaN) pairs produce no edges.
5. Invalid threshold, duplicate/non-string names, malformed/asymmetric matrices,
   infinite values, and coefficients outside [-1, 1] fail clearly.
6. Focused tests and applicable repository lint/build gates pass.

## Existing and expected files

- Existing: backend/app/core/metrics.py returns columns and matrix_original /
  matrix_reduced. Its method parameter is independent of network conversion.
- New: backend/app/core/network.py, backend/tests/test_network.py.
- Task record: docs/tasks/T097.md and docs/tasks/T097.review.md.

## Tests and edge cases

Test inclusive boundaries 0/1, negative edges, monotonic edge counts, isolated
nodes, stable IDs, empty/single-column input, NaNs, JSON serialization, input
validation, and conversion of actual correlation_metrics outputs.
Use synthetic frames only; no access to home-PC data is needed.
Matrix validation is O(columns²), independent of source row count.
Existing metrics replace undefined correlations with zero; this converter cannot
recover that lost information, so raw NaN entries are skipped when supplied.

## Limits and unknowns

Backend module: 300 nonblank lines/file, 50/function.
Tests: 400 nonblank lines/file, 60/function.
T098's rendering schema is not yet defined; use explicit conventional
id/label and source/target fields. This task does not determine node positions.
