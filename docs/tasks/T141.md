At analysis T141 todo; T132/T140 done. Delegated selection; problem.md §6-1.

## Scope and acceptance
Add explain_relationship_changes(metrics, cluster_report, threshold=.5,
after_exclusion=None, dispersion_ratios=None, change_tolerance=.01, boundary_band=.05).
Use T132 topology; split maintained into strengthened/weakened/maintained by
absolute-r change beyond tolerance. Preserve new/lost/absent and sign reversal.
Causes are evidence-backed candidates, not proof of causation:
- outlier_exclusion: supplied same-method post-exclusion original coefficient
  differs materially and moves closer to reduced coefficient; attach measured deltas.
- cluster_representation: observed cluster reduction, stronger |r|, and supplied
  pair within-cluster dispersion ratio <1; label inference explicitly.
- threshold_boundary: lost/new edge with both |r| near threshold and small signed
  difference; attach boundary distances. May coexist with other causes.
- no_material_change or unresolved when there is no supporting evidence.
Do not invent outlier/dispersion evidence from cluster counts. Return result,
causes, evidence, method, threshold, plus existing pair/count data.

## Files/tests/limits
New relationship_causes.py and test_relationship_causes.py. Test outcomes, both
methods, each cause alone/combined, missing evidence, opposite-direction outlier
effects, mismatch methods/columns, sign flip, threshold boundaries, tolerance
boundaries, input preservation, empty and JSON-finite output, malformed parameters.
Validate cluster report counts (T140 schema); avoid implicit causal claims.
Backend limits 300 nonblank/file, 50/function; tests 400/file, 60/function.
No API/UI/report wiring or raw-data dispersion calculation (caller supplies evidence).
Default tolerances are configurable engineering heuristics, not statistical thresholds.
