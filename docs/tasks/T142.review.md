# T142 Adversarial Review

## 검토 결과

- 신규 실행은 선택된 Reduction의 실제 cluster report를 result detail에 저장한다.
- API는 저장된 projection/correlation을 재사용하며 파이프라인을 재실행하지 않는다.
- 성공, 비군집, undefined 상관, 잘못된 그룹·임계값·상관 결과 테스트가 통과했다.
- 전체 backend 테스트 326개가 통과했다.

## 재검토

- cluster 방식에서 저장된 cluster report가 없으면 422를 반환하고, 비군집 fallback은 random/stratified에만 적용된다.
- 원본·축소 projection의 모든 점을 선언된 차원과 대조하며 불일치는 422로 거부한다.
- 두 회귀 시나리오를 포함한 관련 테스트 12개와 lint가 통과했다.
- 수정은 기존 전체 테스트 326개 통과 이후 지적된 두 경로로 한정되며 기존 성공 응답 계약을 바꾸지 않는다.

## 발견 사항

수정 필요 또는 차단 사항 없음.
