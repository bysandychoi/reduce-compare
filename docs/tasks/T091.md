## 범위와 완료 기준

PCA/UMAP 투영 결과를 원본(밀도/서브샘플)과 축소본으로 표시

1. 투영 방법 전환 가능
2. 축 범위 동기화

## 구현 계획

1. 실행 시 투영 원본/축소 특징을 로컬 캐시에 저장하고 API 요청 방식으로 실제 PCA/UMAP 2D 좌표를 만든다.
2. 원본과 축소본 전체 좌표에서 공통 범위를 계산해 나란히·겹쳐보기 SVG에 동일 적용한다.
3. 로딩·오류 상태와 점 수를 표시하고 API 표본 상한으로 DOM 크기를 제한한다.
