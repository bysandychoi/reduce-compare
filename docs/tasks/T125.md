## 주의할 점
- **새 파일**: `docs/guide/` 디렉토리가 아직 없으므로 먼저 생성하고 파일을 작성해야 합니다.
- **샘플 데이터 찾기**: 문서에 실제 돌릴 수 있는 예시 명령을 제시하려면, 저장소에 있는 샘플 데이터(샘플 CSV 폴더)를 확인해야 합니다. 없으면 synthetic 샘플을 작은 규모로 만드는 것을 고려합니다.
- **"단위당 행 수" 그래프**: `plot_distribution.py`의 52~60줄에서 `unit_rows` 파라미터로 히스토그램이 그려집니다. 이 그래프가 무엇(각 단위가 갖는 행 수의 분포)인지, 왜 필요한지(단위 크기 분포 확인) 설명해야 합니다.
- **limit 적용 순서**: `units_limits.py`의 apply_limits 함수를 보면, split_limits로 행 필터(row_limits)와 단위 필터(unit_limits)를 나누고, row_limits를 먼저 적용한 뒤, 단위 필터를 순서대로 적용합니다. 뒤의 컬럼이 앞 컬럼 값을 줄일 수 있다는 점(정확한 개수가 보장되는 것은 마지막 컬럼)을 강조해야 합니다.
- **--sets 멈추는 이유**: `units_sets.py`의 _stop_reason 함수를 보면, 중복이 많거나 stale(50회 연속 중복)일 때 vs 시도 상한에 닿았을 때 메시지가 다릅니다. 이를 명확히 구분해 설명합니다.

## 리뷰 1 반영
- 중요 1(대문자 예시): 명령·출력·`--columns` 예시를 실제 데이터 표기(소문자 `eqp_id`/`mask_id`)로 통일하고 출력은 실행 결과 그대로 붙임. "컬럼 이름은 데이터에 적힌 그대로(대소문자 포함)" 안내 추가.
- 중요 2(순서): "`--unit` 컬럼은 어디에 적어도 마지막, `--unit`에 없는 컬럼끼리는 적힌 순서대로"로 수정하고 실제 예(eqp→mask 106 lot, mask→eqp 116 lot) 추가.
- 중요 3(원본 뜻·시간): limit 예시에 `원본 117행 → 축소 111행` 줄과 "원본은 행 필터 뒤 데이터" 설명 추가, 화면 결과 절에도 같은 안내. 시간은 lot 제한 없음 ~1분 / 117행으로 줄인 뒤 ~7초로 구분.
- 중요 4(연습 예제): 층 규칙("층 값은 한 단위 안에서 같아야 함", '여러 층에 걸쳐' 경고 뜻)을 개념 절에 추가. 연습 명령을 `--unit store_id,region,plan --strata region,plan`으로 바꿔 경고 없이 실행되고 단위당 행 수 1~9로 그래프 연습이 되게 함(실행 출력 첨부).
- 사소: 자동 탐색 1% → 실제 7.21% 이유(--min-units), `--limit-mode sample`이 장비·마스크에도 적용됨, 예시 그림이 이전 버전 출력이라는 안내, '건너뜀'이 어떤 옵션에 해당하는지와 `--columns`(오류)·`--show-dist`(조용히 제외) 차이, 남은 lot이 조금 많을 때 세트끼리 lot이 겹침.
- 리뷰 2 사소: 옵션 표·자주 겪는 상황의 대문자 예시를 소문자로 통일 (대소문자 안내 문장 2곳만 의도적으로 대문자 유지).
