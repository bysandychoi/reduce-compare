# T148 Adversarial Review

## 검토

- 군집 표와 관계 변화 표의 숫자·상태·원인은 실제 핵심 함수 출력이다.
- 생성 JSON은 두 번 실행해 동일한 해시를 보였고 공개 URL은 HTTP 200이다.
- 가이드에서 T147/T148 두 HTML을 연결하며 화면과 문서에 목업임을 표시한다.

## 재검토

- 원본 180개 표본과 실제 대표 22개의 `방문`·`구매` 좌표를 같은 원본 분위수 범위로 정규화하고 실제 군집 라벨 색으로 표시한다.
- 좌표와 라벨이 JSON payload에 저장되며 HTML과 PNG 모두 같은 payload를 사용한다.
- 원본/대표 점 구름이 나란히 표시되어 누락된 군집을 표와 함께 확인할 수 있다.
- 수정 후 생성 JSON 결정성, 스크립트 lint, 공개 URL 200, PNG 시각 검사를 다시 통과했다.
