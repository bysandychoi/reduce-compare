# T056 — 명령 한 줄 실행 스크립트 (폴더 → 결과)

## 문서 성격과 현재 상태

기존 작업의 사후 보완 문서다. 당시 Task Analysis·리뷰 기록을 새로 만든 것으로 취급하지 않는다.

- 기준: 2026-10-01 dev `019ee84`
- 백로그 상태: `done` / 에픽: `E5` / 예상: 30분
- 후행 작업: 없음

## 쉽게 이해하기

웹 화면 없이 폴더를 입력해 축소본·리포트·비교 그림을 파일로 만드는 명령이다.

## 의존 작업

- [T052](T052.md): `done` — 추천 축소 방식 자동 선택

## 범위와 완료 기준

별도 설명이 없어 제목과 다음 완료 기준을 작업 범위로 사용한다.

1. python3 scripts/run_reduce.py <폴더> 로 점수·축소본 CSV·리포트·비교 그림 생성
2. 웹 화면 없이 동작

이 문서는 범위 밖의 기능 구현, 백로그 상태 변경, 새 리뷰 판정을 수행하지 않는다.
