# T014 Task Analysis — 실행 스크립트 작성

- Task: T014, 실행 스크립트 작성
- Status: `todo` at analysis time; must move to `in_progress` before application changes.
- Estimate: 20 minutes
- Dependency: T013 (`done`)
- Downstream tasks: none
- Active branch: `dev`

## Scope

- Add one cross-platform Python command that starts the FastAPI and Vite development servers together.
- Prefer the repository's backend virtual environment when it exists.
- Start Vite with Node directly so the launcher owns the actual server process rather than an intermediate package-manager shell.
- Stop both servers when either exits or the user interrupts the launcher.
- Fail early with actionable messages when required local dependencies are missing.
- Document the one-command local startup flow.

## Non-goals

- Installing Python or Node dependencies automatically.
- Opening a browser automatically.
- Production process management, service installation, containers, or deployment.
- Dynamic port selection or configuration UI.
- Restart-on-change beyond the existing Vite development behavior.

## Technical approach

- Create `scripts/dev.py` using only the Python standard library.
- Resolve repository paths from the script location so the command works from any current directory.
- Use `backend/.venv` Python when available, falling back to the interpreter that runs the launcher.
- Invoke Uvicorn as a Python module and Vite through Node's installed `vite/bin/vite.js` entry point.
- Poll both children; if either exits, report the exit and terminate the other.
- Handle Ctrl+C and always clean up owned child processes.

## Acceptance criteria

1. One command starts both backend and frontend servers.
2. The frontend root responds on port 5173 and its `/api/health` proxy reaches the backend on port 8000.
3. Ctrl+C or one server exiting stops the other owned process.
4. Missing virtual environment packages, Node, or frontend dependencies produce a clear non-zero failure.
5. The script stays within repository line limits and passes Ruff.
6. README documents prerequisites and the startup command.

## Edge cases and risks

- Running from outside the repository: all child working directories must be absolute and repository-derived.
- Missing `backend/.venv`: fallback Python may lack Uvicorn; the error must name the prerequisite.
- Missing `node_modules`: fail before starting only one half of the app.
- Port already occupied: the corresponding child should exit and trigger cleanup of the other.
- Ctrl+C differs across Windows and POSIX; cleanup must rely on direct owned processes and bounded terminate/kill fallback.
- A child can exit before both are fully ready; the launcher must still clean up its sibling.
