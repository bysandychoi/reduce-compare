## 완료 기준 대조

1. 원본 행 수, 축소 행 수, 축소 비율, 추천 방식, 종합 점수의 다섯 항목을 선택 그룹의 `GroupResult`에서 직접 표시한다.
2. 축소 비율은 `reduced_rows / original_rows * 100`으로 계산하며 원본이 0일 때 `0.00%`로 처리한다. 알려진 방식 코드는 한글 이름으로 변환하고 알 수 없는 코드는 원문을 보존한다.
3. `GroupSummary`가 현재 선택된 `group` 객체를 `SummaryCards`에 전달하므로 탭 전환 시 다섯 값이 함께 교체된다.

- 행 수는 로케일 구분자를 적용하고 점수는 소수점 한 자리로 고정해 API 숫자 값을 안정적으로 표현한다.
