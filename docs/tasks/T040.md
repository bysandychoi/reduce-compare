기존 작업의 사후 보완 문서다. 당시 Task Analysis·리뷰 기록을 새로 만든 것으로 취급하지 않는다.

## 쉽게 이해하기

평균·표준편차와 분포 모양이 얼마나 달라졌는지 숫자 컬럼별로 비교한다.

## 의존 작업

- [T027](T027.md): `done` — 특징 행렬 변환

## 범위와 완료 기준

축소 기준 컬럼 중 수치형에 대해 평균·표준편차 차이, KS 통계량 계산

1. 동일 데이터 비교 시 KS=0

이 문서는 범위 밖의 기능 구현, 백로그 상태 변경, 새 리뷰 판정을 수행하지 않는다.

## 관련 요구사항

[problem.md](../../problem.md)의 §5 유사도 평가를 참고한다. 제목과 절 구성은 작업 시작 때 다시 확인한다.

## 현재 코드 근거와 관련 파일

- [backend/app/core/metrics.py](../../backend/app/core/metrics.py) — 현재 존재하는 참고 파일.
- `numeric_metrics`: 평균·표준편차 차이와 KS 통계량 (T040). KS는 대표 행을 그대로 비교한다.

## 검증 근거와 다음 확인

- [backend/tests/test_metrics.py](../../backend/tests/test_metrics.py) — 기존 테스트 11개 함수. 해당 Task 기준을 모두 입증하는지는 재검토 필요.
- 확인 명령: backend에서 `python -m pytest -q tests/test_metrics.py`
- 이번 보완에서는 문서·코드 연결과 백로그 기준을 확인했다. 기능 테스트 재실행이나 성능 측정은 하지 않았다.
- 위 완료 기준별로 입력과 기대 출력을 대조하고 실제 실행 결과를 다음 리뷰에 남긴다.

## 경계 사례와 위험

자기 비교, 상수·결측, 빈 축소본, 유한 점수와 가중치 처리, 지표의 해석을 확인한다.

## 줄 수 제한

core 파일 300/함수50, API 파일200/함수40, backend 테스트400/함수60, TSX250/함수80, TS200/함수50, scripts200/함수50 (공백 제외). 정확한 적용 규칙은 [hooks/config.json](../../hooks/config.json) 참고.

## 확인되지 않은 내용

- 당시 작업자, 정확한 변경 목록, 당시 실행 명령·검사 결과는 기존 기록이 없는 한 알 수 없다. 현재 구현이 당시 구현과 동일하다고 단정하지 않는다.
- 문서의 상태는 위 기준 시점 스냅샷이며 이후 상태 변경을 자동 반영하지 않는다.
