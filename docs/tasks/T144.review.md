# T144 Adversarial Review

## 검토

- 신규 군집 실행은 원본/대표 점 군집 ID와 이상치 마스크를 저장한다.
- report API는 `original_indices`로 원본 메타데이터를 projection 순서에 맞춘다.
- UI는 두 점 구름에 공통 좌표 범위를 사용하고 규모·배율·이상치를 표시한다.
- 관련 backend 테스트 30개와 frontend lint/build가 통과했다.

## 재검토

- `clusterColor`가 군집 ID에 황금각 hue를 적용하며 공유 모듈로 분리되어 T145 표에서도 동일한 매핑을 사용할 수 있다.
- API가 모든 군집 값을 음이 아닌 정수로, 이상치 값을 실제 boolean으로 검증하고 손상값을 422로 거부한다.
- 손상 메타데이터 회귀 테스트를 포함한 backend 테스트 30개와 frontend lint/build가 통과했다.
- 신규 TS/TSX와 수정 backend 파일이 라인 제한 이하다.

## 발견 사항

수정 필요 또는 차단 사항 없음.
