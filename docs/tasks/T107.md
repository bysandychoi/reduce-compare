## 주의할 점
- RED 상수는 plot_compare.py 15행에만 정의되고, plot_distribution.py는 import로 참조하므로 한 곳만 수정하면 됨
- 색상 후보 #2563EB는 이미 검증됨 (원본 회색 #8B93A1 대비 ΔE 22.4, protan 시뮬레이션 19.9, 배경 대비 3:1 이상)
- plot_compare.py의 _scatter() 함수는 alpha=0.5로 반투명 처리되므로 시각적으로 최종 색상이 조정될 수 있음
- 샘플 데이터 생성 후 생성된 PNG 파일을 열어 육안으로 색상 대비를 확인하는 것이 중요함

## 작업 기록
- 축소본 색 `RED`를 `#C2410C`(주황) → `#2563EB`(파랑)로 변경. 원본 `#8B93A1` 유지.
  - dataviz 검증 스크립트: 원본 회색 대비 일반 시야 ΔE 22.4, 색각 이상(protan) ΔE 19.9, tritan 12.3, 바탕 대비 3:1 이상 PASS. 회색의 "채도 부족(회색으로 읽힘)" 판정은 원본을 바탕 기준 회색으로 두려는 의도이므로 유지.
- 색 상수를 고치면서 훅이 `save_comparison()` 52/50줄 초과(기존 상태)를 반려해, 범주 비율 막대 그리기를 `_group_bars()`로 분리했다(동작 동일).
- 확인: `make_sample_data.py --clean`(6000행) → `run_reduce.py`의 compare_A.png, `run_reduce_units.py --unit store_id --strata region,plan --ratio 0.2 --show-dist region,plan,channel`의 distribution_A.png 모두 축소본이 파란색.
- 범위 밖으로 새 태스크 등록: 결측이 섞인 층화 컬럼에서 `grouped.combo_key` TypeError, `_pick_font()`가 한글 글리프 없는 글꼴(IPAGothic) 선택.
