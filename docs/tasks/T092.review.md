# T092 적대적 리뷰

Verdict: PASS

## 완료 기준 대조

- 3차원 PCA/UMAP 좌표를 API에서 실제 생성하고 Plotly `scatter3d`로 회전 가능하게 표시한다.
- 나란히 보기에서 한 플롯의 `scene.camera` 변경을 다른 플롯에 전달하며 재귀 이벤트는 guard로 차단한다.
- 겹쳐보기에서는 원본과 축소본을 색이 다른 두 trace로 같은 3D 장면에 표시한다.

## 경계·회귀 검토

- Plotly는 3D 선택 때 동적 import되어 초기 앱 청크에 포함되지 않는다.
- 컴포넌트 해제와 모드 변경 때 기존 플롯을 purge해 WebGL 자원을 정리한다.
- API 차원은 정수 2~3으로 제한하며 3D 응답의 모든 점이 세 좌표인지 테스트한다.
- 데이터 요청의 취소·로딩·오류 처리는 2D와 동일하게 유지한다.
- 샘플 이미지는 합성 좌표임을 안내서에 명시했다.
