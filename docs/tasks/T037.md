# T037 — 이상치 판정과 대표 제외

## 문서 성격과 현재 상태

기존 작업의 사후 보완 문서다. 당시 Task Analysis·리뷰 기록을 새로 만든 것으로 취급하지 않는다.

- 기준: 2026-10-01 dev `019ee84`
- 백로그 상태: `done` / 에픽: `E3` / 예상: 25분
- 후행 작업: [T140](T140.md)

## 쉽게 이해하기

군집 중심에서 유난히 먼 행을 이상치 후보로 표시하고 대표 선택에서 제외한다.

## 의존 작업

- [T007](T007.md): `done` — 희소 군집 최소 대표 수·이상치 기준 결정
- [T033](T033.md): `done` — 군집 기반 대표 추출 구현

## 범위와 완료 기준

군집 중심까지의 거리 상위 0.1%를 이상치로 판정해 대표 후보에서 제외, 제외 건수 기록

1. 이상치는 축소본에 포함되지 않음
2. 제외 건수·인덱스 반환

이 문서는 범위 밖의 기능 구현, 백로그 상태 변경, 새 리뷰 판정을 수행하지 않는다.

## 관련 요구사항

[problem.md](../../problem.md)의 §4 축소 및 대표값을 참고한다. 제목과 절 구성은 작업 시작 때 다시 확인한다.
