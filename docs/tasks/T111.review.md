# T111 adversarial review

## 검토 범위

- 기존 구조 지표 서브샘플 상한 및 추가 회귀 테스트
- 50만 행 벤치마크와 120초 기준 비교
- `problem.md` §8의 범위 한계 기록

## 검증

- `trustworthiness_score`는 작은 입력에서는 전체 행을 사용하고 큰 입력은 `TRUST_SUBSAMPLE`(3,000)까지만 sklearn 지표에 전달한다. 추가 테스트가 작은 입력과 초과 입력을 각각 검사한다.
- `coverage_metrics`는 작은 입력 전체와 초과 입력의 `COVERAGE_SUBSAMPLE`(20,000) 상한을 `sampled` 결과로 검증한다.
- 전체 지표 테스트 15개 통과, Ruff/compileall 통과.
- 500,000 그룹 A 행(합성 그룹 포함 총 625,000행) 재측정은 60.41초로 120초 이내다. 시간 측정은 합성 생성, 업로드 및 브라우저 렌더링을 제외하며 문서도 이 제한을 명시한다.
- 구현이 이미 기준 상한을 사용하고 있어 수치/알고리즘 변경을 피하고 회귀 테스트만 보강한 결정은 불필요한 지표 정밀도 손실을 막는다.

## 발견 사항

없음. 테스트는 실제 데이터 행을 외부로 보내지 않고, 비용이 큰 trustworthiness 계산은 spy로 표본 크기를 확인한다.

Verdict: PASS
