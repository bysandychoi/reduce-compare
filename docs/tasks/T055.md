## 범위와 완료 기준

1. Pydantic 모델로 정의되고 직렬화 가능
2. 그룹 요약·지표·점수 곡선·방식 비교·투영 그래프 좌표 포함
3. T054 내부 결과 객체에서 API 스키마로 변환 가능

## 구현 계획

1. `backend/app/models/results.py`에 중첩 결과 모델을 정의한다.
2. NumPy 좌표와 인덱스를 JSON 안전한 목록으로 변환하는 팩토리를 제공한다.
3. 실제 샘플 폴더 파이프라인 결과가 JSON 왕복 가능한지 테스트한다.
