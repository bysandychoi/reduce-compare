## 쉽게 이해하기

지금 어떤 단계인지, 얼마나 진행했는지 알려주는 조회 기능이다.

## 의존 작업

- [T062](T062.md): `done` — 축소 실행 API (백그라운드)

## 범위와 완료 기준

단계별 진행률과 현재 단계명 조회

1. GET /jobs/{id}/status가 0~100 진행률 반환
2. 실행 전·대기·실행·완료·실패 상태와 현재 단계명 반환
3. 실패 시 사용자에게 노출할 오류 메시지 포함

## 구현 계획

1. T062 상태 파일에 `progress`, `stage`, 선택적 `error`를 함께 저장한다.
2. GET `/jobs/{id}/status` 응답 모델을 정의하고 실행 전에는 `idle`을 반환한다.
3. 차단 워커로 실행 중 상태를 관찰하고 성공·실패·없는 job 경계를 테스트한다.
