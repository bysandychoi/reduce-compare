## 완료 기준

1. 통과 — handler가 `defaultGraphSettings()` 전체 기본값, X/Y/Z projection 축, 해당 그룹의 projection method를 한 번에 복원한다. 현재 graph kind와 side/overlay mode는 명시된 대로 보존한다.
2. 통과 — 기본 HTML button은 키보드/마우스 작동을 제공한다. Summary 토글 바깥에 있어 클릭이 `<details>` 토글을 전파하지 않으며 focus-visible 표시가 있다.
3. 통과 — 선택 graph kind/mode는 그대로이고, GraphSettingsPanel 및 렌더러 props가 동일한 settings state를 사용한다.
4. 통과 — reset handler는 설정/축/투영 state만 변경한다. `useVisualization`은 축·투영 변경으로 표시 데이터를 요청할 수 있지만 축소 실행 함수는 호출하지 않는다.
5. 통과 — frontend lint/build 통과.
