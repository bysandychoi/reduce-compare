# T147 Adversarial Review

## 재검토

- 계산 payload는 고정 seed 표본 축소 후 요구된 네 핵심 함수를 호출해 생성되며 두 번 실행한 JSON 해시가 동일하다.
- HTML에는 요약 카드, 두 네트워크, 관계 변화 순위, 실제 선택 쌍 산점도, 목업 표시가 있다.
- 원본·축소본 SVG는 동일한 `positions()`를 사용한다.
- 공개 URL은 HTTP 200을 반환하고 frontend build 및 스크립트 lint가 통과한다.
- PNG에도 Pearson/Spearman 탭과 `|r| ≥ 0.50` 임계값이 추가되어 HTML과 같은 한 화면 구성을 보여 준다.
- 선택 쌍 산점도의 HTML과 PNG 좌표는 실제 원본·축소 데이터 행을 공통 범위로 정규화한 값이다.
