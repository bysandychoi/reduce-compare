## 완료 기준 점검

1. `settingsForGraph(graph)` 결과를 순회하고 판별 유니온의 네 타입을 각각 range, color, select, checkbox로 렌더링한다.
2. `graph` 변경 시 정의 목록을 다시 필터링하므로 네트워크 전용 `networkLayout`과 산점도 전용 `pointSize`가 서로 노출되지 않는다.
3. 전체 설정 상태가 `GraphExplorer`에 있어 패널 항목이 언마운트되어도 값이 유지되며, 변경 콜백은 해당 key만 불변 갱신한다.
4. 모든 입력에 고유 `id`, 연결된 label, `aria-describedby`가 있고 범위 현재값은 output으로 표시된다.
5. `npm.cmd run lint --silent`와 `npm.cmd run build --silent`가 통과했다. Vite의 Plotly 청크 크기 경고는 기존 번들 구조에 대한 비차단 경고다.

## 경계·회귀 점검

- 범위 입력은 `valueAsNumber`가 유한할 때만 상태를 갱신한다.
- 색상과 select 값은 스키마가 제공한 유효 기본값에서 시작하고 브라우저 기본 입력 제약을 따른다.
- `useId()` 접두사와 설정 key 조합으로 패널 인스턴스 간 ID 충돌을 피한다.
- `auto-fit/minmax`와 720px 단일 열 규칙으로 좁은 화면의 카드 넘침을 억제한다.
- 합성 시각 샘플은 문서에 포함됐고 이미지 내부에 `SAMPLE`이 있으며 한국어 글리프가 정상 표시된다.
- TSX 비공백 줄 수는 신규 컴포넌트 53줄, GraphExplorer 138줄로 제한 이하다.
- 제공된 Computer Use 환경에 브라우저가 없어 실행 화면 자동 조작은 불가능했지만, 정적 타입 빌드와 렌더 경로 검토에서 차단 결함은 발견되지 않았다.
