## 주의할 점
- **한글 글꼴**: 이 환경에는 한글 글꼴이 없으므로, 스크립트 실행 시 `--font /path/to/noto-sans-cjk.ttf` 형태로 외부 지정. 글꼴 파일은 scratchpad에 미리 준비하고 저장소에는 커밋하지 않는다.
- **색 규칙**: plot_compare.py의 ORIG(회색), RED(파랑), BG(배경) 상수를 그대로 사용한다.
- **_pick_font() 활용**: 한글 지원 폰트 딕셔너리를 반환하는데, 사용자 지정 --font가 있으면 우선 적용한다.
- **예제 데이터**: 좋은 축소(높은 점수), 나쁜 축소(낮은 점수) 두 가지 사례를 충분히 대표적으로 준비한다.
- **재현 가능성**: 스크립트를 다시 실행해도 같은 점수의 그림이 나와야 한다 (시드 고정, 결정적 계산).

## 작업 기록
- `scripts/make_metric_figures.py`(171/200줄): overview / numeric / categorical / correlation / structure / unit_size 6개 그림을 `docs/images/metrics/`에 만든다. 각 그림의 점수는 실제 함수(`numeric_metrics`, `categorical_metrics`, `correlation_metrics`, `coverage_metrics`+`trustworthiness_score`(structure_metrics와 같은 0.5/0.5 식), `unit_size_score`) 결과다. 예제 데이터는 고정 seed(7, sample random_state)라 같은 글꼴이면 바이트까지 같은 그림이 다시 나온다(확인함).
- 한글 글꼴: `--font <ttf>`로 지정(이번 생성은 나눔고딕 OFL, 저장소에 미포함). `--font`가 없으면 설치된 글꼴 중 한글 글리프가 실제로 있는 것을 찾는다(아래 리뷰 1 반영 참고).
- 색: 원본 `ORIG`(회색), 축소본 `RED`(#2563EB 파랑), 바탕 `BG` — plot_compare.py 상수 재사용. 상관 행렬은 부호를 나타내는 발산형 색(PRGn 보라-초록, -1~1)을 쓴다 (리뷰 1 반영으로 RdBu_r에서 변경).
- 구조 그림의 투영 신뢰도는 원본만으로 계산되는 현재 구현(T043 재확인 항목)이라 두 예에서 같은 값(100)으로 나온다 — 설명 문서(T127)에 명시 예정.

## 리뷰 1 반영
- 중요 1(깨진 그림 덮어쓰기): `_pick_font` 대신 `_has_hangul(path)`로 글꼴 파일의 실제 글리프를 확인한다. '원·본·가' 글리프가 모두 있고 서로 달라야 통과한다(LastResort처럼 모든 글자에 같은 대체 글리프를 넣은 글꼴 제외). `--font`가 그 조건을 못 넘거나, `--font` 없이 설치된 글꼴 중 통과하는 것이 없으면 **그림을 쓰기 전에** 종료한다.
  - 확인: DejaVuSans·없는 경로 → 종료, 파일 0개. `--font` 없음 → 이 환경에서는 LastResort를 건너뛰고 GNU Unifont(한글 음절 글리프 있음)를 골라 한글이 읽히는 그림 생성. 저장소 그림은 나눔고딕으로 생성.
  - 스크립트에 쓴 모든 비ASCII 문자가 나눔고딕에 있는지 확인(누락 0). 화살표(→)는 나눔고딕에 없어 계산식 표기로 바꿈.
- 사소: 구조 점수는 `structure_metrics`를 직접 호출. 구조 그림에 "2차원 예제라 투영 신뢰도는 항상 100" 명시. 상관 히트맵을 파랑이 없는 PRGn(보라-초록)으로 바꿔 '파랑=축소본'과 겹치지 않게 함. 개요 그림에 `overall_score`로 계산한 예(94.6·83.1·91.5 → 89.7) 추가.
- 다시 생성해도 6개 그림 바이트 동일. 188/200줄, ruff 통과.
