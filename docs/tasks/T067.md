## 범위와 완료 기준

그룹별 컬럼 목록·타입·기본 선택값·해제 사유 조회, 사용자 선택 저장

1. GET/PUT /jobs/{id}/groups/{gid}/columns 동작
2. 0개 선택 저장 시 400 오류
3. 없는 그룹·컬럼과 중복 선택을 명확한 클라이언트 오류로 처리
4. 그룹별 선택을 원자적으로 저장하고 다음 GET에 반영

## 구현 계획

1. `backend/app/api/columns.py`에 조회·저장 모델과 엔드포인트를 둔다.
2. T061의 작업/그룹 계산을 재사용하고 절대 경로는 응답하지 않는다.
3. 그룹별 독립 JSON 파일로 저장해 서로 다른 그룹의 동시 갱신 충돌을 피한다.
4. 기본값, 저장 왕복, 빈/없는/중복 입력과 없는 job/group을 API 테스트한다.
