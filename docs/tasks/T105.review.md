# T105 Adversarial Review

## 검토 결과

- 설정 스키마에 네트워크 전용 `networkLayout`과 `correlationThreshold`가 있고 T101 패널이 두 컨트롤을 자동 생성한다.
- `GraphExplorer`의 단일 설정 상태가 레이아웃과 임계값을 `CorrelationNetworks`에 전달하므로 원본·축소본에 동시에 적용된다.
- 임계값 변경은 네트워크 조회 effect만 다시 실행하며 축소 파이프라인은 호출하지 않는다.
- 원형 배치는 빈/단일/다중 노드를 처리한다. force 배치는 원형 좌표에서 결정론적으로 시작하고 난수 없이 반복한다.
- force 계산은 겹친 좌표와 누락된 엣지 끝점을 방어하며 결과를 38~382 범위로 제한해 반지름 29 노드가 420 viewBox 안에 남는다.
- 레이아웃 계산은 그래프별로 독립적이므로 원본과 축소본의 서로 다른 연결 구조를 각각 표현한다.
- 합성 샘플은 두 레이아웃을 비교하고 `SAMPLE` 및 정상 한국어 글리프를 포함한다.
- frontend lint와 build가 통과했다. Plotly 대형 청크 경고는 기존 비차단 경고다.
- 변경 TS/TSX 파일은 파일·함수 라인 제한 이하다.
