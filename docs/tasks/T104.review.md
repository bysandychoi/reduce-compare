## 완료 기준

2. 통과 — 선택 축의 좌표와 레이블이 SVG/Plotly 양쪽에 연결된다. 빈 표본은 기본 bounds와 빈 point layer를 사용하고, 결측·무한 컬럼 값은 422로 거부한다.
3. 통과 — original_indices/reduced_indices로 원본·축소 CSV 좌표를 표본에 정렬한다. T103 reduced_weights와 reduced point 표본 순서는 같은 내부 인덱스를 사용한다.
4. 통과 — 알 수 없는/비수치 컬럼, 2D에서 z_axis, 사용 불가 투영 차원, density 모드의 raw column 선택을 검사한다.
5. 통과 — 축 선택 변경 시 표시용 visualization GET만 요청한다. projection 재계산 함수는 투영법/차원 변경 분기에만 실행되며 축소 run은 호출하지 않는다.
6. 통과 — API 전용 테스트 10개, 전체 backend 332개, Ruff/compileall, frontend lint/build 통과.
