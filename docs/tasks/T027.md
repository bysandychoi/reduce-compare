## 범위와 완료 기준

수치형 표준화, 범주형 원-핫(고카디널리티는 빈도 인코딩)으로 계산용 행렬 생성

## 현재 코드 근거와 관련 파일

- [backend/app/core/prepare.py](../../backend/app/core/prepare.py) — 현재 존재하는 참고 파일.

- `_encode_categorical`: 저카디널리티는 원-핫, 고카디널리티는 빈도 인코딩.

주의: ONEHOT_MAX_CARDINALITY=20. 그보다 종류가 많은 범주는 빈도 인코딩을 쓴다.
