### 지적

1. [중요] `frontend/src/HeatmapMatrix.tsx:44`와 `frontend/src/styles.css`의 `.heatmap-value`가 모든 셀 숫자를 같은 짙은 글자색으로 그려, |r|이 큰 진한 셀에서 숫자가 읽히지 않는다.
   - 재현: 원본 대각선 `1.00`은 `rgb(190,55,55)`, 강한 음의 상관 `-1.00`은 `rgb(42,112,160)` 배경인데 숫자는 항상 `#17202a`다. 첨부 샘플에서도 `1.00`이 진한 적색 위에서 거의 사라진다.
   - 색 대비를 대략 계산하면 적색 배경과 짙은 글자의 명도 차가 작아, tooltip을 띄우기 전에는 값 자체를 읽기 어렵다. 완료 기준의 셀 수치 확인이 강한 상관에서 성립하지 않는다.
   - 고칠 방향: `Math.abs(value) >= 0.55 * limit`인 정의된 셀에는 흰색 텍스트 클래스를 적용한다. undefined 셀은 현재 짙은 대시를 유지한다. 원본·축소본과 대칭 차이에서 같은 절댓값 기준을 사용한다.
