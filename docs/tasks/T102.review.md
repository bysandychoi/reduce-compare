## 완료 기준 점검

1. 통과 — 기본/색각친화/고대비 팔레트와 사용자 지정 원본·축소본 색이 지원 그래프 렌더러에 전달된다. 히트맵/네트워크에는 작동하지 않는 색상 컨트롤을 노출하지 않는다.
2. 통과 — 2D/컬럼 그래프 렌더링은 props로 색을 받으며 데이터 조회 effect의 의존성과 API 호출 조건은 색 설정에 의존하지 않는다. 3D Plotly 그래프는 클라이언트 렌더만 갱신한다.
3. 통과 — 그래프 종류 변경과 관계없는 `GraphExplorer` state로 설정이 유지된다. 두 팔레트는 서로 다른 시리즈 색을 사용한다.
4. 통과 — 스키마 검증은 select 허용값을 제한하고, 사용자 지정 색은 기존 6자리 HEX validator를 사용한다. 초기 설정은 유효한 기본값이다.
5. 통과 — 프론트엔드 lint와 build 성공. Vite는 기존 Plotly 번들이 500kB를 넘는다는 경고를 출력하지만 빌드 실패는 아니다.

## 위험 및 범위 확인

- 백로그 설명의 “컬럼 기준 색상 매핑” 중 산점도의 점별 원본 컬럼 범주 매핑은 입력 데이터 계약과 UX가 정해져 있지 않아 작업 분석 문서에서 명시적으로 제외되었다. 이번 변경은 색각친화 팔레트와 원본/축소본 색 적용에 집중한다. 점별 컬럼 범주 매핑은 별도 작업으로 정의할 필요가 있다.
- 실제 브라우저 상호작용 확인은 수행하지 않았다. 합성 시각 샘플은 존재하고 한국어 글리프가 있는 Malgun Gothic으로 생성되었지만 실제 런타임 증거는 아니다.
- 의미상 색상인 heatmap/network와 반영 리포트 색상은 이번 변경 대상이 아니다.
