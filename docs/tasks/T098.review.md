### 지적

1. [중요] `backend/app/api/correlation_networks.py:40`가 undefined mask를 `np.asarray(mask, dtype=bool)`로 강제 변환해, 손상된 문자열·숫자 마스크를 정상 boolean으로 받아들인다.
   - 재현: `undefined_original=[["false", "false"], ["false", "false"]]`는 모든 문자열이 비어 있지 않아 전부 `True`가 된다. API는 422가 아니라 200을 반환하며 원본 관계를 전부 "측정 불가"로 숨긴다. `[[0,1],[1,0]]`도 묵시적으로 false/true가 된다.
   - Task Analysis는 "마스크 크기 불일치·손상 결과 422"를 명시했고, 완료 기준도 손상된 상관 결과의 안전한 안내를 요구한다. 현재는 조용히 거짓 그래프를 만든다.
   - 고칠 방향: 변환 전에 mask가 `list[list[bool]]`이고 각 행 길이가 columns 수인지 명시적으로 검사한다. 문자열·정수·`np.bool_` 아닌 JSON 값은 거절한다. 회귀 테스트에 문자열 mask를 추가해 422를 단언한다.
