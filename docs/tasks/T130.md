## Scope and acceptance
`problem.md` requires Pearson/Spearman selection. Existing correlation_metrics
already forwards method to pandas but lacks Spearman tests and returns a
different schema for fewer than two numeric columns. Support only these two
methods and return the same complete result keys for both, including empty and
single-column input. Keep default Pearson and existing matrix rounding and
NaN-to-zero matrix policy. Avoid nonfinite correlation-of-correlations output.
No sampling, pipeline/API/UI wiring, or score-weight changes. Sampling is
permitted by the backlog, not mandatory; performance work remains separate.
