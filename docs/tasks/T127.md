## 주의할 점
- **trustworthiness 주의사항** (T043.md 기록): 현재 trustworthiness_score()는 축소본을 인자로 받지 않고, 원본 서브샘플을 PCA로 2차원 투영한 뒤 투영 품질을 계산한다. 원본→축소본 관계 보존과 같은 의미라고 단정하지 않으니 이 점을 문서에 명시해야 한다.
- **그림에 포함된 점수**: 각 그림에는 왼쪽(좋은 축소)과 오른쪽(나쁜 축소) 예시가 있고 각각의 점수가 표시되어 있다. 문서에서 이 구체적인 점수를 활용하여 "88점이면 양호, 60점이면 개선 필요" 같은 기준을 제시하면 해석이 쉬워진다.
- **링크 추가 방식**: README.md와 run_reduce_units.md의 기존 구조를 무시하지 않고, 자연스러운 위치에 "자세한 내용은 [유사도 지표 설명 문서](../guide/similarity_metrics.md)" 형태로 추가하면 된다.
- **코드와 일치 확인**: 각 산식을 쓰기 전에 해당 파일의 라인을 꼭 확인한다 (예: metrics.py L45 numeric 가중치, L66 categorical 가중치, L114 correlation 가중치, structure.py L82 structure 가중치, catmetrics.py L34 ratio_similarity 가중치).

## 리뷰 1 반영
- 중요: 범주형 예시 설명을 그림대로 고침 — 81.6점은 D 누락 + A 50%→66%(최대 비율 차 0.158은 A)의 결과. D만 빼고 나머지 비율을 유지하면 87.5점(직접 계산: JS 0.158, 최대 차 0.049)임을 따로 적음.
- 사소: 수치형 59.6점 감점 내역(KS 약 25, 평균 약 11, 표준편차 약 4.5) 추가 / 상관 최대 차 0.56은 방문-할인(부호 바뀜) 쌍 / "100×(1−차이) 꼴"을 분포·상관·비율·단위 크기로 한정하고 커버리지·구조는 별도 설명 / run_reduce.py 사용자는 비교 그림·report JSON 컬럼별 점수를 보도록 안내 분리 / '무작위 비율 축소'를 `--ratio` 비율 축소와 lot 제한 시 `--limit-mode sample`로 구체화 / 상관 그림은 세 칸·부호 색이라는 예외 명시.
