# T036 — 희소 군집 최소 대표 수 보장

## 문서 성격과 현재 상태

기존 작업의 사후 보완 문서다. 당시 Task Analysis·리뷰 기록을 새로 만든 것으로 취급하지 않는다.

- 기준: 2026-10-01 dev `019ee84`
- 백로그 상태: `done` / 에픽: `E3` / 예상: 25분
- 후행 작업: [T140](T140.md)

## 쉽게 이해하기

작은 군집도 결과에서 보이도록 최소 대표 수를 배분한다. 원본 수나 목표가 너무 작은 경우의 정책은 따로 확인해야 한다.

## 의존 작업

- [T007](T007.md): `done` — 희소 군집 최소 대표 수·이상치 기준 결정
- [T034](T034.md): `done` — 군집 크기 가중치 저장

## 범위와 완료 기준

비례 배분이 30행 미만인 군집은 30행으로 올리고, 총 크기를 맞추도록 큰 군집에서 조정

1. 모든 군집 대표 수 ≥ 최소치
2. 총 대표 수 = 목표 크기

이 문서는 범위 밖의 기능 구현, 백로그 상태 변경, 새 리뷰 판정을 수행하지 않는다.

## 관련 요구사항

[problem.md](../../problem.md)의 §4 축소 및 대표값을 참고한다. 제목과 절 구성은 작업 시작 때 다시 확인한다.

## 현재 코드 근거와 관련 파일

- [backend/app/core/clustering.py](../../backend/app/core/clustering.py) — 현재 존재하는 참고 파일.
- `_plan_allocation`: 군집 크기에 비례해 대표 수를 나누고, 희소 군집은 최소치를 보장한다 (T036).

주의: 현재 _plan_allocation은 비례 배분 후 floor를 적용한다. 목표 총수와 최소치가 충돌하는 경우의 완료 기준 충족은 과거 기록이 없으므로 재검증 대상이다.
