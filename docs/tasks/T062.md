## 범위와 완료 기준

파이프라인을 백그라운드 작업으로 실행

1. POST /jobs/{id}/run 후 즉시 응답, 작업은 백그라운드 진행
2. 저장된 그룹 병합 결정과 컬럼 선택을 실행에 반영
3. 같은 job의 동시 중복 실행을 거절하고 완료/실패 상태와 결과를 원자 저장

## 구현 계획

1. `backend/app/api/runs.py`에 제한된 스레드 풀과 POST 엔드포인트를 둔다.
2. 제출 전 `queued` 상태를 저장하고 워커에서 `running` → `done`/`failed`로 갱신한다.
3. T054 파이프라인과 T055 JSON 스키마를 연결해 `result.json`을 생성한다.
4. 차단 워커를 이용해 응답이 작업 완료 전에 반환되는지, 중복·없는 작업을 테스트한다.
