## 쉽게 이해하기

파일 읽기부터 축소·평가·투영까지 흩어진 기능을 그룹별 한 흐름으로 연결한다.

## 의존 작업

- [T024](T024.md): `done` — 그룹별 데이터 병합
- [T052](T052.md): `done` — 추천 축소 방식 자동 선택
- [T053](T053.md): `done` — 2D/3D 투영 계산

## 범위와 완료 기준

입력 → 전처리 → 크기 결정 → 방식 선택 → 지표 → 투영까지 그룹별 실행

1. 샘플 폴더로 end-to-end 결과 객체 생성
2. 그룹별 준비 결과, 선택 결과, 점수 곡선, 방식 비교, 투영 좌표 반환
3. 처리할 수 없는 그룹은 전체 실행을 중단하지 않고 사유 반환

## 구현 계획

1. 전체 실행 및 그룹 결과 자료형을 `pipeline.py`에 추가한다.
2. 폴더 스캔부터 그룹별 투영까지 기존 도구 중립 함수를 조립한다.
3. 같은 스키마 파일 병합, 결과 객체, 투영 좌표와 실패 그룹 격리를 임시 샘플 폴더로 테스트한다.
