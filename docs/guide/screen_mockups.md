# 화면 목업

실제 앱 구현 전 정보 구조를 검토하기 위한 합성 데이터 기반 예시 화면이다.

- [상관관계 분석 화면](../images/screens/correlation-analysis.html) — 상관 점수, 네트워크, 관계 순위, 선택 쌍 산점도
- [축소 반영 리포트](../images/screens/representation-report.html) — 그래프 구성, 규모, 군집 반영, 관계 변화 원인 후보
- [공장 Scheduling 관계](../images/screens/factory-scheduling.html) — Lot별 가능 설비, Resource, 연결 Spec

두 화면의 숫자는 실제 핵심 계산 함수를 호출해 만들며 실제 사용자 데이터나 완성된 앱 화면이 아니다.
